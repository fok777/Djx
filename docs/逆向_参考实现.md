# 逆向参考：「Flutter 解析工具 8.0」

仅供架构参考（旧版本），新版源码按此改造调用方式。

## 结论：它不靠 Termux，全部内置

| 能力 | 实现方式 | 证据 |
|---|---|---|
| radare2 | **JNI 桥 dlopen**，不是 exec 命令行 | 23 个 `libr_*.so` + `libr2aibridge.so` |
| Capstone 反汇编 | 自研 JNI | `libdisassembler.so` → `capstone.jni.FastDisassembler`（10 个方法） |
| blutter | **exec** PIE 可执行文件 | 23 个 `libblutter_<版本>.so`（名义 .so，实为可执行文件） |
| unidbg | **JNA**（ART 上直接跑，不需要 JVM） | `libjnidispatch.so` → 69 个 `com.sun.jna.Native.*` |
| Unicorn 引擎 | JNI | `libunicorn.so` + `libunicorn_java.so` |
| frida | gadget | `io_frida.so`（125 MB） |

## 1. radare2 的 JNI 桥

`libr2aibridge.so` 导出：

```
Java_com_r2aibridge_R2Core_initR2Core
Java_com_r2aibridge_R2Core_executeCommand
Java_com_r2aibridge_R2Core_openFile
Java_com_r2aibridge_R2Core_closeR2Core
Java_com_r2aibridge_R2Core_testR2
```

→ Java 侧必须是 `com.r2aibridge.R2Core`。
so 内字符串常量（`OK: r_core_cmd_str() works, version:`、`FAILED: r_core_new() returned null`）
表明方法返回 `String`。内部调的是 `r_core_new` / `r_core_cmd_str` / `r_core_free` / `r_core_cmd0`。

### 加载顺序（关键）

`libr_*.so` 之间有依赖，安卓不会到应用私有目录找依赖库，
必须按拓扑序手动 `System.load`，顺序错了直接 `UnsatisfiedLinkError`。

被依赖最多的是 `libr_util.so`（22 个库依赖它）。
`libr2aibridge.so` 必须在 `libr_core.so` **之后**。

顺序见 `Radare2Bridge.LOAD_ORDER`（30 个）。

## 2. unidbg 不需要 JVM（纠正之前的判断）

之前判断「unidbg 是 JVM jar，安卓 ART 跑不了」——**错**。
该 APK 用 JNA（`libjnidispatch.so`）+ Unicorn（`libunicorn_java.so`），
在 ART 上直接跑 unidbg，不需要装 JVM 或 Termux。

## 3. 保活做法

Manifest 里注册了这些广播接收器：

```
BOOT_COMPLETED
LOCKED_BOOT_COMPLETED
MY_PACKAGE_REPLACED
QUICKBOOT_POWERON
```

配合前台服务（`PROPERTY_SPECIAL_USE_FGS_SUBTYPE`，描述写明
"MCP server running as foreground service to maintain persistent
connection with Claude for code analysis tools"）、
`stopWithTask=false`、`extractNativeLibs`、`largeHeap`。

这是它比旧版稳的原因之一：开机自启 + 包更新自启 + 前台服务。

## 4. 加壳情况

`classes.dex` 12.4 MB，但 header 只声明 3 个类、data 段 9.6 KB。
剩余 12.1 MB 在 offset 13084 之后，熵 6.13，非单字节 XOR。
真正的代码被藏起来了——所以工具名只能从字符串池扫到 92 个
（R2\_ 34 / Fr\_ 31 / Ub\_ 21 / Apk\_ 4 / Os\_ 2）。

## 5. frida 模板

`res/raw/frida_template.js` 是 Dart AOT 的 hook 模板：
按 `PointerCompressedEnabled` / `HeapAddressReg=x28` / `NullReg=x22`
解析带标签的 Dart 对象，支持打印字段值。
